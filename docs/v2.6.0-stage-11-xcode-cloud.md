# Этап 11: Xcode Cloud и доставка iOS

**Завершён в релизе 2.6.0 от 11.11.2026.** Пользователь подтвердил успешную
новую Cloud-сборку с этапами 12–13, доставку во внешнее TestFlight-тестирование,
iOS-приёмку и публикацию в App Store. Внешнее beta review и релизный App Review
пройдены. Общие итоги — в [отчёте релиза](v2.6.0-release.md).

## Реализованный результат

- Версии package/Android/iOS и WhatsNew согласованы для 2.6.0 до первого Archive.
- Реальные lockfiles получены resolver на Mac: CocoaPods 1.17.0,
  xcodeproj 1.28.1, Bundler 2.4.10. Cloud устанавливает их frozen, без pod update.
- Сохранены minimum app **15.6** и interactive widget **17.0**.
  Podfile post_install поднимает более низкие/незаданные минимумы Pod-целей
  до 15.6, включая privacy/resource bundles; более высокие минимумы не понижает.
- Подготовлены ci_post_clone/pre_xcodebuild/post_xcodebuild hooks:
  проверка окружения, Node/Yarn/Bundler/Pods, генерация закрытой конфигурации,
  общая нумерация и проверка метаданных полученного архива.
- Оба направления распространения используют **TestFlight and App Store**,
  а не Internal Testing Only. Проверенный TestFlight build пригоден для App Review
  без обязательного нового Archive только ради публикации.
- Source diagnostics выводит предупреждения об источнике сборки, не отменяет
  разрешённые workflow запуски, не требует fetch и полной Git-истории.
- Секреты вводятся в Cloud Secret variables. GitHub repository secrets,
  private config repository и серверные credentials для этого не используются.

## Нумерация и инструменты

`CI_BUILD_NUMBER` одного Cloud-продукта применяется к app, extension и tests.
Marketing version берётся из репозитория. Счётчик не сбрасывается при смене
ветки/workflow; пропуски после неудачных запусков допустимы. Hook сверяет
version/build, bundle IDs и minimum OS обеих целей.

Локальная macOS-проверка выполнена с Xcode 26.4 (17E192); для Cloud пользователь
сообщал Xcode 27.2 (27B52) / macOS 27.2. Hooks используют выбранный workflow
образ и печатают фактические версии, не подменяя DEVELOPER_DIR.

## Проверки и сопровождение

Локальные регрессии покрывают конфигурацию без утечки значений, frozen tools,
shallow/annotated Git tags, build numbers и archive metadata. Последний общий
зафиксированный прогон — **48 suites / 532 tests** и typecheck, успешно 09.11.
Нативный результат подтверждён последующей успешной Cloud-сборкой и выпуском.

Точные команды, имена переменных, workflow и диагностика хранятся в одном месте:

Роли/доступ после переноса — в [инструкции владельцу](v2.6.0-xcode-cloud-owner.md),
основания архитектуры — в [решениях Cloud](v2.6.0-xcode-cloud-research.md).
