# Автоматические данные README

GitHub отображает статический Markdown и не подставляет переменные package.json.
[project-docs.cjs](../scripts/project-docs.cjs) генерирует готовые README-блоки и SVG,
сохраняя доступность картинок без внешнего сервиса бейджей.

| Данные | Источник |
| --- | --- |
| React Native, React, TypeScript, Reanimated, Worklets, Yandex Ads | package.json |
| Версия Node | .nvmrc, основная версия |
| Минимум Android | minSdkVersion в android/build.gradle |
| Минимум iOS | minimum_ios_version в ios/Podfile |
| Клиентские тесты и наборы | Результат полного успешного прогона Jest |

Семь SVG-чипов, их alt-тексты, таблица стека и клиентский счётчик обновляются
автоматически. Исторические показатели выпущенных версий и чип последнего
опубликованного релиза остаются фактами соответствующего выпуска: номер версии
в разработке не объявляется опубликованным релизом.

```bash
yarn docs:sync   # версии + сохранённый результат последнего полного прогона
yarn test:ci     # все тесты; затем актуальные счётчики и версии README
yarn docs:check  # проверка без изменения файлов
```

Число тестов берётся из итогов Jest, включая развёрнутые `test.each`, а не путём
подсчёта строк/файлов. Сохраняются только агрегаты в `docs/project-metrics.json`;
полный временный JSON-отчёт удаляется. Частичный, упавший или прерванный прогон
не заменяет результат проекта. Дополнительные аргументы `yarn test:ci` передаются
Jest и отключают запись метрик, чтобы выборочная проверка не уменьшила счётчик.

При `CI=true` полный успешный прогон проверяет результат и сгенерированные файлы,
не записывая их. Если они устарели, проверка завершается с пояснением: выполнить
локальный `yarn test:ci` и включить обновлённые файлы в обычный коммит.
Автоматических коммитов или дополнительных прав на запись в GitHub не требуется.
Блоки `project:stack` и `project:tests` в README принадлежат генератору.
