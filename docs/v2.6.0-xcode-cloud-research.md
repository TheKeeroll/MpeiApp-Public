# Xcode Cloud: принятые решения для MpeiApp 2.6.0

Решения реализованы: Cloud-сборка, TestFlight и App Store-публикация подтверждены
пользователем, релиз состоялся 11.11.2026. Здесь сохранены архитектурные основания;
операционные команды — в [Cloud README](../ios/ci_scripts/README.md),
результат — в [отчёте этапа 11](v2.6.0-stage-11-xcode-cloud.md).

## Назначение Cloud

Cloud обеспечивает iOS Release Archive в macOS/Xcode и доставку в App Store
Connect/TestFlight. GitHub Actions остаётся независимым контуром TypeScript,
Metro, Android debug APK и proxy; он не получает iOS production-конфигурацию.
Первое подключение потребовало Xcode владельца, обычное сопровождение
сборок и внешнего тестирования выполняется через браузер.

Использован включённый в Apple Developer Program бюджет 25 compute hours/месяц;
подключение дополнительного платного тарифа не входило в реализацию.
Управление членством и подпиской относится к Account Holder; доступные лимиты
и расход видны в аккаунте. Это фиксация принятой конфигурации релиза.

## События и распространение

Фактически согласованы префиксы `release-*` для App Store Connect и
`testflight-*` для публичного TestFlight. Старый проект схемы ios-dev-*/push v2
не является контрактом hooks. Условия запуска определяет workflow;
verify-source только диагностирует неожиданные ветки/теги или неполную историю,
без fetch и без отмены сборки.

Один Archive на событие, режим **TestFlight and App Store**, один продукт MpeiApp
и общий CI_BUILD_NUMBER позволяют выпускать уже проверенный TestFlight build.
Перенос проверенного кода в v2 и выбор бинарного файла для App Review —
отдельные операции; новый Archive не требуется только ради выбора build.

## Repository secrets: возможности и ограничения

GitHub repository secrets предназначены для workflow Actions и не являются
автоматическим источником окружения Xcode Cloud. Передача их через
дополнительный сервер/артефакт/частный config repository добавила бы отдельную
систему доступа и сопровождения. В реализованной схеме этих посредников нет.

Cloud Secret variables содержат только необходимую клиентскую конфигурацию.
Генератор проверяет обязательность, формат URL/портов/путей и не принимает demo
ad IDs для iOS Archive. В сообщениях об ошибках печатаются имена полей, не значения.
Secrets.ts, Swift initializer и .xcode.env.local создаются только внутри checkout
и игнорируются Git. Для локального Mac сохранён существующий закрытый канал.

Secret variables ограничивают доступ при подготовке сборки, но не делают
встроенный в клиент API key или advertising ID серверным секретом.
Token панели S-UI, HMAC cooldown и TLS private keys остаются исключительно на VPS
и не относятся к мобильной конфигурации.

## Воспроизводимость

Node 24 / Yarn 1.22.22, frozen Bundler, CocoaPods 1.17.0 и xcodeproj 1.28.1
закреплены lockfiles и hooks. post_install согласует minimum Pod-целей,
не понижая более высокие требования. App minimum 15.6 и widget 17.0 разделены.
Проверка архива сверяет IDs, версии и минимумы app/extension.

Подпись после transfer использует текущую Team и новые widget/App Group ID;
общий Swift-контракт и entitlements исключают расхождение runtime-контейнера.
Разбор прежних неудачных запусков не является текущей блокировкой релиза.
