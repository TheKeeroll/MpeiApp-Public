# Формы вопросов БАРС для экспериментального автозаполнения

Fixtures подготовлены 12.10.2026 по трём предоставленным HTML.
Личные блоки страницы не копируются. `uslkID`, `qqaID` и ID сотрудника
заменены тестовыми UUID; имя сотрудника — «Тестовый преподаватель».
Сохранены структура полей, классы pager, onclick отправки и `getAnswer`.
Скрипты служат описанием исходного контракта и не исполняются тестами/приложением.

| Файл | Контракт |
| --- | --- |
| [radio-first.html](radio-first.html) | Первый предоставленный вопрос: выбор «Студент» / «Выпускник» из `#tblQuestion tr[data-qi]`, `data-qit=1` |
| [radio-neutral.html](radio-neutral.html) | Второй предоставленный вопрос: два варианта с «Нет»; значение ответа — ID строки, а не текст label |
| [composite-fields.html](composite-fields.html) | Третий предоставленный пример: сотрудник select, шкала 0–10, textarea; `qiID\|p\|значение`, поля соединяются `\|a\|` |
| [free-text.html](free-text.html) | Синтетический отдельный textarea с `data-qi` |
| [other-with-text.html](other-with-text.html) | Синтетический вариант с `data-qit=3` и дополнительным текстом: ID варианта + `\|p\|текст` |
| [completion.html](completion.html) | Синтетическая страница подтверждения по предоставленному контракту SubmitQuestionnaireAnswer |
| [unsupported-file.html](unsupported-file.html) | Синтетическое неподдерживаемое поле: остановка без отправки выдуманного ответа |

Ответы JSON в тестах синтетические и соответствуют обработчику страницы:
`success`, `url`, `error`. Окончательное завершение всегда проверяется свежим
списком анкет; fixtures не доказывают доступность реального БАРС.
