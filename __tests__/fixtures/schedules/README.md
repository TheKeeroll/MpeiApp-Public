# Расписания

Минимизированная форма публичного HTTPS-ответа ts.mpei.ru, повторно проверенная
14.11.2026. Предметы и ФИО заменены, служебные GUID, авторы, почта и прочие
неиспользуемые поля удалены. Сохранены реальные особенности схемы: nullable
group/stream/lecturerUID, listGroups и пустой listOfLecturers.
Discovery person ID и lecturerOid принадлежат разным пространствам.
Фиксированные даты проверяют сортировку и пропущенный день независимо от сети/часов CI.
