# HTML-fixtures обязательных анкет БАРС

Подготовлены 12.10.2026 для этапа 1 плана v2.6.0. Это входные данные
будущих тестов парсера и общего перехвата университетских ответов;
сам парсер и перехват на этапе 0 ещё не реализованы.

Основа — предоставленная HTML-страница и сохранённый рядом JS-ресурс `icc`.
В исходной таблице десять строк: семь обычных незаполненных анкет, одна
обязательная, одна завершённая и одна с истёкшим сроком. Pager сообщает
о восемнадцати записях. Реальная вторая страница не предоставлена.

Логин заменён на `TestStudent`, все `uslkID`/`qqaID`, описания дисциплин,
инициаторы и даты — на тестовые значения. Личные блоки страницы, скрипты,
cookies и настоящие verification tokens не сохраняются. Публичное название
обязательной анкеты на первой странице оставлено; семь колонок, статусы,
классы значков, атрибуты таблицы и устройство pager сохранены. Заголовок
таблицы и навигация сокращены до необходимого для тестов.

| Файл | Происхождение и ожидаемый результат |
| --- | --- |
| [blocked-page-1.html](blocked-page-1.html) | Обезличенная первая страница: banner, 10 из 18 строк, одна обязательная, ссылка на следующую страницу. Блокировка и неполный перечень. |
| [blocked-page-2.html](blocked-page-2.html) | **Синтетический** partial HTML второй страницы: 8 из 18 строк, две обязательные, без banner и без оболочки документа. Последняя страница; вместе с первой позволяет проверить сбор и дедупликацию по ID. |
| [banner-only.html](banner-only.html) | Вариант banner без таблицы: перенос строки, `&nbsp;`, вложенный тег и верхний регистр. Блокировка с пока неизвестными названиями анкет. |
| [required-without-banner.html](required-without-banner.html) | Две обязательные строки без banner, иной порядок классов, дополнительный класс, HTML-сущности. Одинаковые названия с разными описаниями/ID должны сохраниться отдельно. |
| [nonblocking.html](nonblocking.html) | Обычная незаполненная, завершённая и просроченная строки из исходника. Синтетические обычный `divAlert` и красный значок вне таблицы. Блокировки нет. |
| [completed-and-expired-with-stale-icons.html](completed-and-expired-with-stale-icons.html) | **Синтетический** случай: завершённая и просроченная строки сохранили красные значки. Их статусы исключают строки из вызывающих блокировку; banner отсутствует. |
| [login-form.html](login-form.html) | Синтетическая форма входа с фиктивным verification token. Возвращение такой формы вместо целевого раздела означает работу существующего auth flow. |
| [two-factor-form.html](two-factor-form.html) | Синтетическая форма 2FA с фиктивным token. Не должна ошибочно трактоваться как блокировка анкет. |

[cases.json](cases.json) содержит ожидаемые классификации, число строк,
ID обязательных ответов и параметры страниц. `origin` отличает материал
из исходника от синтетических вариантов. ID повторяется между отдельными
fixtures намеренно; внутри пары страниц 1/2 ответы различны.

У `banner-only.html` неизвестна полнота перечня. Статус `available` означает
лишь отсутствие признаков обязательных анкет: он не доказывает, что HTML
подходит конкретному парсеру оценок, студента или другого раздела.

При написании тестов использовать эти файлы локально, без сетевых запросов
и зависимости от абсолютного пути исходной страницы. Отдельно проверять
HTTP 200/redirect, HTML вместо JSON, исключения auth/2FA/QR/внешних сервисов,
поздние ответы после смены аккаунта и ошибки при загрузке следующей страницы.
